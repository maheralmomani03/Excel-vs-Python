# 📈 Day 48: Ad Spend vs. Sales Correlation Analysis
![Cover](../images/95.png)

### 🎯 Objective
Analyzing the statistical relationship between advertising expenditure and generated revenue to determine the effectiveness of marketing investments.

### 💼 Accounting Context
* **Forecasting (CMA):** Using historical correlation to build more accurate sales projections based on planned budgets.
* **Resource Optimization:** Identifying the point of diminishing returns for marketing spend.
* **Performance Reporting:** Providing management with visual evidence of ROI trends.

### 📗 Excel Approach
**Formula:** `=CORREL(Correlation_Analysis[Ad_Spend], Correlation_Analysis[Sales])`

### 🐍 Python Approach
**Logic:** Beyond just a single coefficient, Python's `matplotlib` allows for visual trend inspection via scatter plots, making it easier to spot outliers and patterns.
